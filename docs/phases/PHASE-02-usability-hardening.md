# PHASE-02: Usability Hardening

## Goal

Improve daily-use comfort and reduce friction points discovered during real-world use of the MVP. Focus on overlay positioning, UI sizing controls, hotkey conflict detection, per-output volume, recent phrases, import/export, settings organization, and onboarding flow improvements.

## In Scope

- Overlay position adjustment and persistence
- Better font/UI size controls
- Hotkey conflict detection improvements
- Volume per output device
- Recent phrases / recent messages list
- Import/export phrases
- Better settings organization and navigation
- Improved onboarding / first-run flow

## Out of Scope

- Theme presets or visual overhaul
- Phrase categories/folders/search
- Additional TTS engines
- Voice preset switching or speed/pitch controls

- [ ] Overlay position is user-adjustable and persisted
- [ ] Per-output volume controls functional
- [ ] Phrase import/export working
- [ ] Recent phrases accessible
