# PHASE-03: Comfort & Expression

## Goal

Add visual polish, expanded phrase management, and voice expression features to make the app more comfortable and joyful to use daily without degrading the core send flow.

## In Scope

- Theme presets (dark variants)
- Visual polish and subtle animations
- Better send/success feedback
- Phrase categories, folders, search, favorites, pinning
- Repeat last / resend
- Transcript logging
- Voice preset switching
- Speed and pitch controls
- Optional premium voice path (e.g., ElevenLabs)
- Cached audio for quick phrases

## Out of Scope

- Message queueing
- VRChat OSC integration
- Voice cloning
- Cloud sync or mobile companion

- (created when PHASE-03 becomes active)

## Completion Criteria

- [ ] At least two theme presets available
- [ ] Phrase categories or folders functional
- [ ] Phrase search working
- [ ] Voice speed/pitch adjustable
- [ ] Transcript log accessible
- [ ] Cached phrase audio reduces repeat-playback latency
