# PHASE-06: Quality-of-Life Follow-up

## Goal
Improve everyday overlay speech control and support direct function-key hotkey bindings.

## In Scope
- Global standard TTS playback speed control
- Modifier-free global hotkey bindings, including F13–F24

## Out of Scope
- Per-phrase speed controls
- Changes to phrase cache playback

- [SPRINT-14](../sprints/SPRINT-14.md)

## Completion Criteria
- [x] Standard overlay TTS speed is persisted and adjustable from Voice settings
- [x] Phrase playback remains speed-neutral
- [x] Modifier-free hotkeys can be captured, validated, and registered
- [x] Build: 0 errors, 0 warnings
