# Environment Variables

The app does not use environment variables for configuration. All settings are stored in the JSON config file at `%AppData%\TtsCommunicationTool\config.json`.

## Retype-Specific Variables

If building the documentation site, Retype uses:

| Variable | Purpose |
|----------|---------|
| `RETYPE_KEY` | Retype Pro license key activation |
| `RETYPE_PASSWORD` | Password for protected pages |
